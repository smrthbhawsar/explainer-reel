Yahin aata hai MCP — Model Context Protocol.
Simple bhasha mein: AI ke liye USB-C port.
Ek standard plug, jo har tool mein fit ho jaata hai.
Pehle, har tool apna ek MCP Server banata hai, jo batata hai ki wo kya kya kar sakta hai.
Tumhari AI app ke andar ek MCP Client hota hai, jo in servers se connect hota hai.
Jab tum sawal poochte ho, LLM sahi tool chunta hai, client request bhejta hai, aur server real data ya action wapas laata hai.
Na har app ke liye naya code, na har tool ke liye alag jugaad.
